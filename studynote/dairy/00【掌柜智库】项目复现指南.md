## 一、项目概述与架构决策

### 1.1 项目是什么

**掌柜智库** = 企业级 RAG（检索增强生成）智能知识库问答系统。

```
数据导入流程（7 节点）：
上传文件 → 入口判断 → PDF转MD → 图片处理 → 文档切分 → 主体识别 → 向量化 → 存入Milvus

检索问答流程（7 节点）：
用户提问 → 产品确认 → 向量检索 → HyDE检索 → 网络搜索 → RRF融合 → Rerank重排 → 生成答案
```

### 1.2 技术栈

| 类别 | 选型 | 说明 |
|------|------|------|
| 工作流编排 | LangGraph | 有状态多节点流程图 |
| Web 框架 | FastAPI | 异步 + SSE 流式输出 |
| 向量数据库 | Milvus 2.5.5 (+Attu 2.5.10) | 混合检索（稠密+稀疏向量） |
| 对象存储 | MinIO | 存原始 PDF / 图片 |
| 文档数据库 | MongoDB | 存对话历史 |
| 容器化 | Docker + Docker Compose | 全部中间件容器部署 |

### 1.3 关键架构决策：全 API 方案（本项目与课程原方案的最大差异）

课程原方案是「本地 BGE-M3 + 本地 BGE-Reranker + 本地 GPU」，**本项目改为全 API 方案**：

| 能力 | 课程原方案 | 本项目方案 | 原因 |
|------|-----------|-----------|------|
| LLM 问答 | DashScope API | **qwen-flash** API | 原方案就是 API，不变 |
| 图片理解 | DashScope API | **qwen3-vl-flash** API | 原方案就是 API，不变 |
| 文本向量化 | 本地 BGE-M3 模型 | **text-embedding-v4** API | 4核8G 服务器跑不动本地模型 |
| 检索重排 | 本地 BGE-Reranker | **gte-rerank-v2** API | 同上（gte-rerank 已下线，见坑35） |

**好处**：不下载 GB 级模型、不装 torch/FlagEmbedding、4核8G 服务器足够、开发期几乎零成本（新用户免费额度）。
**代价**：API 按量计费（极便宜，开发期预估 ¥0~5）。
**回退**：本地 `.venv` 是 Windows + CUDA 版本的初始代码，原始 `.env` 备份为 `.env.bak`，以后想切回本地模型方案可参考。

### 1.4 机器分工

```
本地电脑（Windows + VS Code/TRAE + FinalShell）
   │ scp 上传代码 / SSH 远程执行
   ▼
腾讯云轻量服务器 4核8G（Ubuntu 22.04，24h 在线）
   ├─ Docker: Milvus全家桶 + 独立MinIO + MongoDB
   └─ Python 3.11 + uv: 项目代码运行

AutoDL GPU（可选，本项目当前阶段不需要）
   └─ 未来想体验本地模型部署时按小时租用（关机即停，公网IP每次会变）
```

### 6.1 背景：初始代码的占位实现

初始代码 `processor/import_processor/nodes/node_enrty.py`（注意文件名是课程原始拼写 enrty）是**硬编码占位**：

```python
def process(self, state: ImportGraphState):
```

这是课程故意留白的第一个编码任务：**根据文件后缀动态判断**。

### 6.2 完整实现（已写入服务器，复现时覆盖同名文件）

```python
# processor/import_processor/nodes/node_enrty.py

from processor.import_processor.base import BaseNode
from processor.import_processor.state import ImportGraphState


class NodeEntry(BaseNode):
    """
    入口节点：任务分发

    根据导入文件的后缀名设置读取标记：
    - .pdf -> is_pdf_read_enabled = True（后续走 PDF 转 Markdown 节点）
    - .md  -> is_md_read_enabled  = True（后续直接读取 MD 内容）
    - 其他 -> 两个标记都为 False（主图条件路由会直接结束流程）
    """

    name = "node_entry"

    def process(self, state: ImportGraphState):
        import_file_path = state.get("import_file_path", "").strip()

        if import_file_path.endswith(".pdf"):
            return {
                "is_pdf_read_enabled": True,
                "is_md_read_enabled": False,
            }

        if import_file_path.endswith(".md"):
            return {
                "is_pdf_read_enabled": False,
                "is_md_read_enabled": True,
            }

        return {
            "is_pdf_read_enabled": False,
            "is_md_read_enabled": False,
        }
```

**知识点**：节点返回 dict（而不是整个 state）是 LangGraph 的增量合并特性——返回的键自动合并进全局状态。
